# LandslideGuard

AI-Powered Low-Cost Landslide Early Warning & Risk Mapping System

## Problem

Hilly terrain prone to landslides often lacks affordable early warning systems.

## Proposed Solution

LandslideGuard combines weather and terrain data with machine learning to estimate landslide risk for specific locations and provide early warnings.

## Key Features

- AI-based landslide risk prediction
- Dynamic risk mapping
- Weather and terrain analysis
- Explainable risk factors
- Location-based early warnings

## Technology Stack

- Python
- Scikit-learn
- FastAPI
- React
- Leaflet
- OpenStreetMap
